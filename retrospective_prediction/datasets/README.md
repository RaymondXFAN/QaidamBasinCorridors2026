# Datasets Directory

This directory contains all data used by the permafrost settlement prediction experiment.

## Folder Structure

- `raw/` — Downloaded raw data files from public sources (TPDC, PANGAEA, NCDC, etc.)
  - Files here are in their original format (GeoTIFF, CSV, mixed formats)
  - These files are downloaded by `download_datasets.py`

- `processed/` — Preprocessed data in `.npz` format, ready for model training
  - Each `.npz` file contains: X, y, adj_matrix, geo_features, and metadata
  - Generated by `download_datasets.py` preprocessing step, or by simulation fallback

## How to Download Data

Run the standalone download script from the project root:

```bash
python3 download_datasets.py
```

This script will:
1. Attempt to download all candidate datasets (A1 chaimu, A4 qaidam, A5 northeast, A8 yeniugou)
2. Save raw data into `datasets/raw/`
3. Preprocess available data into `datasets/processed/` in `.npz` format
4. Generate a status report `datasets/download_status.txt`

## If Downloads Fail

Public data sources (TPDC, PANGAEA) may require:
- Registration and authentication
- Manual browser-based download
- Institutional access

If automatic downloads fail:
1. Check `datasets/download_status.txt` for details on which datasets failed
2. Visit the URLs listed in the status report manually
3. Place downloaded files in `datasets/raw/` and re-run `python3 download_datasets.py --preprocess-only`
4. The experiment will automatically fall back to simulation data if no real data is available

## Simulation Fallback Data

When no real data is available, the experiment generates physically realistic simulation data:
- Based on Stefan equation + thermodynamic models
- Parameters calibrated to Qilian Mountain / Qaidam Basin permafrost conditions
- Suitable for framework validation, but NOT for publication results
- Generated automatically by `run_main.py` when `data_source: "simulation"` is set in config

## Important Notes

- Simulation data is for framework validation only
- For publication, replace with real data from public sources
- The `.npz` format is NumPy's compressed archive format, loadable via `np.load(path)`
